## P2 背景与痛点

- **版式**：3 个痛点图标卡（误采误食 / 信息难辨 / 识花 App 缺安全）+ 底部深绿结论横幅
- **要点**：
  - 误采误食：不认识的中草药，凭经验采摘有风险；
  - 信息难辨：网络信息鱼龙混杂、真假难辨；
  - 识花 App 缺安全：只认鲜植物，不含用药安全提示；
  - 结论：核心缺口——识别 ≠ 安全，本项目把「识别」与「用药安全」绑定。

**讲解词**：
> 先说背景痛点：大众遇到不认识的草药容易误采误食；网上信息真假难辨；市面识花 App 只能认植物、不含用药安全提示。所以核心缺口是——识别不等于安全，本项目把识别和用药安全绑定。

## P7 技术架构

- **版式**：纵向架构框图（前端 → 后端 → 识别引擎 / 问答 / 数据）+ 底部容错横幅
- **要点**：
  - 前端：Vue 3 + Vant + Tailwind（H5 响应式）；
  - 后端：Python FastAPI（识别代理 · 知识库 · 问答）；
  - 识别引擎：**双通道**——本地模型（主）→ 百度植物识别（兜底），Mock 仅作保底；
  - 多模态问答：通义千问 Qwen（主）→ 知识库结构化（降级）；
  - 数据：SQLite · 172 味药材知识库。

**讲解词**：
> 技术上是前后端分离：前端 Vue3 + Vant，后端 FastAPI。识别引擎是**双通道**设计——自训练本地模型是主通道，低置信或异常自动回退百度兜底，Mock 仅作保底；多模态问答用通义千问，失败降级本地知识库；数据层 SQLite 内置 172 味药材知识库。链路容错保证演示不断。

## P8 核心算法

- **版式**：左双通道流程图（含**双阈值拦截**标注 + 3 条策略卡）＋右**训练日志截图**
- **要点**：
  - 本地模型：ResNet50 迁移学习 · 93 类 · 验证集实测 77.8%（如实标注）；
  - **双阈值拒识**：top-1 置信度 < 0.75 **或** top-1/top-2 概率差 < 0.15（分布平坦、疑似 OOD）→ 回退百度；
  - 百度低置信（< 0.6）→ 不给结论，降级相似列表 + 引导重拍；
  - 双通道调度：本地主 → 百度兜底 → Mock 仅保底；
  - 右侧配**训练日志**截图（PyCharm GPU · Epoch 行）。

**讲解词**：
> 核心算法是自训练的 ResNet50 分类模型，覆盖 93 类常用药材，验证集实测准确率约 77.8%，如实标注。识别用**双阈值拒识**：本地 top-1 置信度低于 0.75，或 top-1 与 top-2 概率差低于 0.15（分布平坦、疑似未知物种）时，自动回退百度兜底；百度低置信也不给直接结论，而是展示相似品种引导重拍，避免误导。右侧是我在 PyCharm 里用 GPU 跑的 2 轮训练日志，2 分钟完成。

## ★ 实机演示（PPT 全部讲完后，约 2 分钟）

**【操作】切换到浏览器（已提前打开可快速操作的页面）**
- ① 相册上传一张在库普通药材图（如黄芪）→ 识别 loading → 结果页，快速指向安全色标 + 置信度 + 通道；
- ② 返回上传一张**毒性药材**图（如附子）→ 全屏警示页，强调「只有『我已了解风险』一个按钮，无跳过入口」→ 点击进入，指向防雷警报卡；
- ③ 回到结果页，点快捷标签问一句 → 展示回答 + 免责声明；再点**麦克风**语音问一句 → 语音转文字上屏 → 出回答。

**【台词（衔接）】**
> 这是刚才讲到的识别与安全链路：普通药材几秒出结果，绿色标签、置信度、识别通道一屏可见；毒性药材强制全屏警示，不可跳过；结果页还能文本或语音追问，回答自动附"仅供参考，不构成诊断或处方"的免责声明。

**【故障预案】**
| 故障 | 处理 |
| --- | --- |
| Qwen 不可用 | 不操作，等降级展示：「AI 不可用自动切换本地知识库，不阻塞主流程——这是降级设计。」 |
| 语音被拦 / 置灰 | 改用文本输入，点快捷标签继续演示。 |
| 识别 channel=baidu | 「当前是百度兜底通道，展示容错设计。」 |
| 图片拍糊 / 低置信 | 走相似品种列表 + 引导重拍，避免误导。 |

**演示结束收尾**：
> 这就是完整的识别、安全、问答闭环。我的介绍和演示就到这里，感谢各位老师，欢迎批评指正。
