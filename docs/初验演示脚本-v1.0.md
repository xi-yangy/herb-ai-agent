## 1. 初验定位与时长分配

- **一句话定位**：一款「拍照识别 + 用药安全提示 + 多模态问答」的中草药识别智能体；
- **演示总时长**：**3 分钟**（180 秒），分五幕；答辩 2 分钟（预判 3–5 个高频问题，见第 3 节）；
- **功能覆盖**（对应 PRD 验收项）：
  - F1/F2 拍照与相册上传识别 → 第二幕；
  - F4 高危强制全屏警示（不可跳过）→ 第三幕 ★；
  - F12/F13 多模态图文+语音问答、语音输入 → 第四幕 ★；
  - F5 功效主治/禁忌查询、分层信息卡 → 第二幕一句话带过；
  - 百科 / 历史 / 我的等扩展页已完整上线，**不占主线时长**，作答辩与延伸加分项（见 3.1）。

### 1.1 五幕时间轴

## 2. 三分钟演示主线（五幕走位与台词）

> 说明：`【操作】` 为现场动作，「台词」为可照念的话术（可据自己语言微调，**关键数字与合规表述不建议改动**）。每幕台词按对应时长估算语速（约 4–5 字/秒），照念即可控时。

### 第一幕：开场（15 秒）

- 【操作】停留在首页 `HomeView`，大屏可见品牌区「灵草 · 多模态中草药识别」与三个技术亮点标签。
- 「台词」：
  > 这是我们团队做的「多模态中草药图像识别智能体」。核心就三件事：**拍照识别中草药、给出用药安全提示、还能用文字或语音追问**。

### 第二幕：识别主流程（50 秒）

- 【操作】点击「相册上传」，选择一张**在库普通药材**演示图（如黄芪）→ 识别 loading → 自动跳转结果页 `ResultView`。
- 【操作】手指指向**安全等级色条**（普通 = 绿色）与药材卡片（名称、置信度、识别通道），再向下滑动示意「白话科普 / 专业药典」分层卡。
- 「台词」：
  > 现在演示核心流程。上传一张黄芪照片，几秒出结果——左上角绿色标签代表普通药材，同时给出置信度和识别通道。这里特别说明：后端按「**自训练本地模型 → 百度植物识别 → 模拟数据**」三通道调度，本地模型是我们用 ResNet50 在自建药材库上训练的主通道，减少对单一第三方 API 的依赖。同一个结果我们还做了分层展示：白话科普卡面向普通消费者，专业药典卡面向从业者。

### 第三幕：高危强制警示（45 秒）★ 演示亮点

- 【操作】返回首页，上传一张**毒性药材**图片（如白矾，知识库 `safety_level=毒性`，且在本地 ResNet50 模型类别内，识别走 local 主通道）→ 识别结果自动跳转全屏警示页 `WarningGateView`。
- 【操作】刻意演示「无关闭入口」：页面只有「我已了解风险」一个按钮，无返回、无 X、无跳过。
- 【操作】点击「我已了解风险」→ 进入结果页，指向顶部**鉴别防雷警报卡**（本药材 vs 易混淆高危品种辨析 + 警示语）。
- 「台词」：
  > 这是本项目最重要的安全设计：**高危判定宁严勿松**。上传白矾——毒性药材——识别后直接弹全屏警示。大家注意，这个页面**没有关闭按钮、没有跳过入口**，用户必须确认已知晓风险才能进入结果。以白矾为例，药典列为有毒，内服须严格控制用量，警示页直接给出毒性说明和"遵医嘱、切勿自行服用"的提醒。结果页顶部还有防雷警报卡，把白矾和它的煅制品枯矾做外观、用法对比辨析。这个警示逻辑上线前会经药师复核。

### 第四幕：多模态问答 + 语音输入（50 秒）★ 演示亮点

- 【操作】在结果页滚动到问答区 `QaPanel`，先点快捷标签「有什么禁忌」→ 展示 Qwen 回答气泡 + 底部免责声明。
- 【操作】点击麦克风按钮 → 用语音问「这味药和什么容易混淆？」→ 语音转文字上屏 → 发送 → 展示回答。
- 「台词」：
  > 结果页还支持**多模态追问**。点这个快捷标签问一句"有什么禁忌"，回答由通义千问结合当前识别结果生成，你上传的那张图也会作为上下文一起参考，做图文联合问答；同时自动附带"仅供参考，不构成诊断或处方"的免责声明。再试一下语音：直接说"这味药和什么容易混淆"——语音走浏览器原生的 Web Speech API，用 Chrome 直接可用、免费、无需额外 SDK。如果 AI 不可用，系统会自动降级为**本地知识库的结构化展示**并标注提示，保证演示链路不断。

### 第五幕：收尾（20 秒）

- 【操作】回到首页。
- 「台词」：
  > 总结一下：**识别给结论、安全给警示、问答给延伸**——我们用多模态的方式，把"这是什么药"和"怎么安全用"串成一条完整链路。另外底部"百科 / 历史 / 我的"三个扩展功能也都做完了，答辩时可以展开讲。演示到这里，欢迎老师提问。

## 3. 两分钟答辩要点（预判高频问题）

> 按项目**实测口径**回答，未验证项如实说明，不引用厂商自述作承诺。每个应答约 30–45 秒，2 分钟约能答 2–3 题，优先接好前两问。

| 可能的问题 | 精炼应答（30–45 秒） |
| --- | --- |
| **识别准确率多少？** | 本地自训练模型在验证集实测约 **77.8%**，如实标注、未虚标。为弥补单模型局限，我们做了三通道：本地置信度低于阈值（0.75）自动回退百度植物识别，百度不可用再兜底模拟数据，保证链路不中断。页面会显示实际命中的通道和置信度。 |
| **为什么要自训练模型？** | 三个原因：一是摆脱对单一第三方 API 的依赖，识别自主可控；二是针对自建药材库做迁移学习（ResNet50 预训练权重微调），提升在库药材的针对性识别；三是作为实训创新点，走通了「数据采集 → 训练 → 部署 → 识别」完整闭环。 |
| **三通道怎么协同？** | 调度顺序：本地模型优先，低置信（0.75 以下）或未启用时回退百度植物识别，凭证缺失或异常再兜底 mock。每次识别结果都标注实际命中的通道，页面可见可查。 |
| **Qwen 不可用怎么办？** | 问答超时（默认 30s）或未配置凭证时自动降级为知识库结构化展示，回答带 fallback 标记并提示「已切换至本地知识库展示」，不报错、不中断，识别主流程完全不受影响。 |
| **数据与隐私怎么保证？** | 用户上传图片仅用于本次识别，前端完成后即清除，服务端不持久化原始图片；首次使用有权限说明弹窗，可拒绝并降级（拒绝相机切相册）；全流程固定免责声明，高危警示无跳过入口，知识库高风险字段上线前经人工复核。 |

### 3.1 可主动引出的延伸话题（如时间富余）

- 分层信息卡双视角设计（白话科普 + 专业药典）对两类目标用户的覆盖；
- 桌面端 ≥1024px 结果页分栏布局，投屏可读（PRD U1/U2）；
- 百科 / 历史 / 我的扩展页：药材百科与详情、识别历史回看（原图仅存本机、服务端不持久化）、收藏与登录同步，构成「识别 → 结果 → 知识沉淀」完整产品闭环。

## 4. 今晚演练 Checklist（初验前一天执行）

### 4.1 环境启动与就绪

- [ ] 后端：以**系统 Python** 后台启动（`Start-Process -FilePath "python" -ArgumentList "run.py" -WorkingDirectory "d:\CodeBuddy\herb-ai-agent\backend" ...`，stdout/stderr 重定向日志），**禁用 `.venv`**；
- [ ] 确认后端日志出现「**本地模型已加载（N 类，设备 cuda/cpu）**」；
- [ ] **懒加载预热**：本地模型在首次识别时才加载（需数秒），正式演示前先跑一次识别冒烟，让模型完成加载，避免现场首图卡顿；
- [ ] 前端：`cd d:\CodeBuddy\herb-ai-agent\frontend` 后 `npm run dev:raw`（勿用裸 `npm run dev`）；
- [ ] 健康检查：`curl.exe -s -o NUL -w "HTTP %{http_code}" http://localhost:5173` 与 `http://localhost:8001/api/health` 均返回 200；
- [ ] 演示浏览器为 **Chrome / Edge**（语音输入需要），已允许麦克风权限。

### 4.2 主链路冒烟（三通道 + 亮点验证）

- [ ] 识别一张在库药材图 → 结果 `channel=local`；
- [ ] 毒性药材图（如白矾）→ 触发全屏警示，确认**无跳过入口**；
- [ ] 易混淆品种图（如金银花）→ 结果页出现「易与断肠草混淆」防雷警报卡（可选）；
- [ ] 结果页追问一句 → 返回 Qwen 真实回答 + 免责声明；
- [ ] 语音问一句 → 语音转文字上屏并成功回答；
- [ ] 可选：临时关闭 Qwen 或断网，验证自动降级为知识库展示不报错。

### 4.3 演示图片物料清单

- [ ] ① 在库**普通药材**（如黄芪）——第二幕主链路；
- [ ] ② **毒性药材**（如白矾，`safety_level=毒性`，且在本地模型类别内走 local 通道）——第三幕强制警示；
- [ ] ③ **易混淆品种**（如金银花）——防雷警报卡演示（可选，时间富余时加）；
- [ ] ④ 低置信/陌生图（可选）——「低置信降级 + 引导重拍」应急演示。
- 建议：图片提前放入相册/桌面随手可及的位置；若现场可实拍，第二幕改用**相机拍照**更真实。

### 4.4 时间彩排

- [ ] 按第 2 节五幕完整走 2–3 遍，全程计时，确保 ≤ 3 分钟；
- [ ] 每幕台词熟读一遍，控时不足时优先保第三、四幕两个亮点；
- [ ] 答辩预演：请队友/同学按第 3 节随机抽 2–3 问模拟。

### 4.5 突发预案备忘（完整版见结项演示脚本第 5 节）

| 故障场景 | 现场处理 / 话术 |
| --- | --- |
| Qwen 超时 / 不可用 | 不做操作，等降级展示：「AI 问答不可用，我们自动切换到了本地知识库的结构化展示，不影响识别主流程——这是我们的降级设计。」 |
| 识别显示 `channel=baidu` | 多半是用了 `.venv` 启动后端；话术：「当前是百度兜底通道，本地模型依赖的 torch 只装在系统 Python——这也正好展示了容错设计。」 |
| 语音按钮置灰 / 麦克风被拦 | 提示改用文本输入，点快捷标签继续演示问答能力。 |
| 断网 / 后端不可达 | 首页会提示后端离线；改用 mock 演示或演示已打开的页面：「系统对异常做了兜底，识别失败会回退演示数据，链路不中断。」 |
| 图片拍糊 / 低置信度 | 走「低置信度降级」页：相似品种列表 + 重新拍摄引导，避免误导。 |
