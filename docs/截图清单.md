## 四、操作步骤（一次跑通）

1. 后端：系统 Python 后台启动（`python run.py`），确认日志出现「本地模型已加载（93 类，设备 cuda/cpu）」；
2. 前端：`cd d:\CodeBuddy\herb-ai-agent\frontend` 后 `npm run dev:raw`；
3. Chrome 打开 `http://localhost:5173`，建议用**桌面端窗口（1280×800，投屏形态）**；
4. 按上面顺序逐项操作 + 截图（`Win+Shift+S` 区域截图即可）；
5. 截图以编号命名保存，便于套模板时对应。

> 提示：截完一张勾选一项；必截 01/02 全部在前端页面操作完成，无需改任何代码。
